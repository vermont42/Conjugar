Geometry / prep:
  The matador is the kidnapped bullfighter — a STATIC one-frame goal figure that
  stands beside the bull on the game's top platform. tools/blender/gen_matador.py
  cleans the raw purchase (drops ~25 junk objects + the cape, hides the heavy
  vendor hair), CLEARS the Daz IK constraints and poses the arms hands-on-hips in
  pure FK, and repositions/scales the montera onto the head, producing
  source/matador_posed.blend. That is rendered front-on (--view back = the FACE;
  the Genesis-8 model faces -Y) via tools/blender/render_sprites.py with the new
  --matador per-garment cel mode (MATADOR_MESH_COLORS: jacket/pants = blue,
  vest/hat = gold, socks = pink, shoes = dark-red = the bull's hoof color, shirt =
  cream, body = skin) + --toon + --outline at --size 512, then union-cropped by
  pack_or_rename.sh to Conjugar/Assets.xcassets/Game/matador.imageset (188x452).

Reuse / animation:
  The mesh is fully rigged and animatable — a future animated matador would
  restore/drive the Daz IK targets (lHand_IK / rHand_IK) or hand-key FK like the
  dancer (gen_dancer_action.py), then render N frames through render_sprites.py
  --matador. Today he is a single static frame.

Raw BLEND/FBX/RAR-textures kept git-ignored under tools/blender/source/ (only the
rendered PNG + this license file are committed), per the spike's asset-handling
rule. This repo is public/AGPL and ships only the rendered 2D sprite, not the raw
3D asset.
