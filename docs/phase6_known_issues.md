# Phase 6 — known issues (RESOLVED)

**Resolved 2026-06-13:** reír (6B-4) and oír (10) are now end-anchored — the literal
slot residue was replaced with composed features (raise `e→i` + `a-i` accent +
collapse-ii + `o-yhiatus`, whose accent set was extended to PI-1p / IMP-2p), so all
their prefixed compounds (freír, sonreír, sofreír, refreír, desleír, engreír; desoír,
entreoír) conjugate on their own stem. See `docs/blog_notes.md` under that date.
